## 快速上手

1. 開啟 **[線上網址](https://kn713606pp.github.io/mahjong-record/)**
2. 點右上角 **「新增牌局」** 輸入第一場紀錄
3. 點 **「查看儀表板」** 即可看見統計分析

> 所有資料儲存在**瀏覽器本機**（localStorage），不上傳至伺服器。

## 新增牌局

點右上角藍色 **「新增牌局」** 按鈕。

### 基本資訊
| 欄位 | 說明 |
|------|------|
| 日期 | 牌局日期（預設今天）|
| 開始/結束時間 | 預設為現在時間往前 3 小時 |
| 地點 | 支援歷史紀錄自動完成 |
| 底 / 台 | 底注與台費 |
| 抽頭/場費 | 若有抽頭請填入，系統會自動驗算四人總和 |
| 備註 | 特殊牌型、趣事等，支援語音輸入 |

### 計分方式

**籌碼制**（推薦）
- 填入四位玩家姓名與各自輸贏籌碼數
- 系統驗證：四人總和 + 抽頭 **必須等於 0**
- 若已設定對戰組合，可用 **⚡ 快速套用** 下拉選單自動填入玩家名稱

**現金制**
- 僅記錄「我」的個人輸贏金額
- 適合只知道自己輸贏、不清楚他人數字的情況

> 💡 地點和玩家名稱欄位旁有麥克風圖示，點擊可使用**語音輸入**（需瀏覽器支援）

## 列表模式

首頁預設為列表模式，顯示所有牌局紀錄。

### 日期分組
紀錄依日期分組，每組標題顯示：
- 日期
- 當日場次數
- **當日主玩家輸贏合計**（綠色為贏、紅色為輸）

### 篩選功能
| 欄位 | 說明 |
|------|------|
| 關鍵字搜尋 | 搜尋玩家名稱、地點、備註 |
| 開始/結束日期 | 限定日期範圍 |
| 清除篩選 | 一鍵清空所有篩選條件 |

### 每張牌局卡片
- 右上角：**日曆圖示**（匯出 ICS）、**鉛筆圖示**（編輯）、**垃圾桶**（刪除）
- 籌碼制顯示四人戰績；現金制顯示個人輸贏

## 行事曆模式

點右上角切換至 **「行事曆」**。

- 有紀錄的日期顯示**淺藍色底色**
- 格子內直接顯示**主玩家當日損益金額**（綠色/紅色）
- 格子右下角顯示當日**場次數**
- 點擊任意日期格子 → 開啟該日詳細牌局清單
- 左右箭頭切換月份

## 戰績儀表板

點 **「查看儀表板」** 按鈕。

### 頂部統計卡片
依當月、本年、生涯統計，包含：
- 本月場次 / 輸贏 / 場均 / 勝率
- 目前**連勝 / 連敗**條數（🔥 或 💔）
- 本年輸贏、生涯總計
- 最大單場勝利 / 最大單場敗北

> 統計對象可透過左上角「分析對象」下拉選單切換為任意玩家

### 四個分析分頁

**📊 當月比較**
- 長條圖比較當月所有玩家輸贏
- 可勾選/取消特定玩家

**📈 累積損益**
- 折線圖顯示主玩家歷場累積損益走勢
- 可一眼看出是否在上升或下滑趨勢

**🤜 對戰分析**
- 與每位對手同場時的勝率與分差
- 找出你的「剋星」和「軟柿子」

**⏰ 時段分析**
- 依星期（週日～週六）分析輸贏
- 依時段（早上 / 下午 / 晚上 / 深夜）分析輸贏

### 匯出本月紀錄
儀表板右上角 **「匯出本月紀錄」** → 下載整月 `.ics` 行事曆檔案

## 對戰組合管理

點 Header **紫色「對戰組合」按鈕**。

### 設定組合
1. 點任一**空格子**（最多 10 組）
2. 填入**組合名稱**（如「龍潭老班底」）
3. 填入**四位玩家姓名**（玩家名稱支援歷史自動完成）
4. 點「儲存組合」

### 使用組合
新增牌局 → 選「籌碼制」→ 出現紫色 **⚡ 快速套用對戰組合** 下拉選單
→ 選擇組合後 4 位玩家姓名**自動填入**

### 編輯 / 刪除
管理介面中，每個已設定格子右上角有「編輯」和「刪除」按鈕。

## 快速記錄輸贏

適合現金制的快速記帳，不需開完整表單。

1. 在列表頁篩選列找到 **「快速記錄輸贏」** 展開按鈕
2. 填入日期、地點（選填）、輸贏金額
3. 點「快速記錄」→ 立即存入，以**現金制**模式記錄

> 正數 = 贏錢、負數 = 輸錢（例如輸 500 填 `-500`）

## 資料備份與還原

### 備份（匯出 JSON）
點 Header 綠色 **「備份」按鈕** → 下載 `mahjong-backup-YYYY-MM-DD.json`

建議定期備份，尤其在換瀏覽器或換電腦前。

### 還原（匯入 JSON）
點 Header 藍色 **「還原」按鈕** → 選擇備份的 `.json` 檔案
→ 確認後全部資料還原

> ⚠️ 匯入會**覆蓋**現有所有資料，請確認後再執行

### 換電腦/換瀏覽器的遷移步驟
1. 舊瀏覽器：點「備份」下載 JSON
2. 新瀏覽器開啟 App：點「還原」選擇剛才的 JSON
3. 完成，所有紀錄完整移轉

## 安裝到手機主畫面

本 App 支援 PWA（Progressive Web App），安裝後可**離線使用**。

**iOS（Safari）**
1. 用 Safari 開啟 App 網址
2. 點底部 **「分享」** 圖示（方框帶箭頭）
3. 選 **「加入主畫面」**
4. 點「加入」完成

**Android（Chrome）**
1. 用 Chrome 開啟 App 網址
2. 點右上角選單（三個點）
3. 選 **「安裝應用程式」** 或 **「加入主畫面」**
4. 點「安裝」完成

安裝後在主畫面點擊 Icon 即可開啟，外觀與原生 App 相同。

- 所有資料儲存於**瀏覽器的 localStorage**，不經過任何伺服器

- 若使用無痕模式，關閉視窗後資料會消失

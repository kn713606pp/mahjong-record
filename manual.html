📝 新增牌局

點右上角藍色 「新增牌局」 按鈕開啟表單。

基本資訊

欄位說明
日期牌局日期，預設今天
開始 / 結束時間預設為現在往前推 3 小時
地點輸入地點，支援歷史紀錄自動完成下拉
底 / 台底注與台費金額
抽頭 / 場費若有抽頭費用請填入；系統會自動驗算總和
備註記錄特殊牌型、趣事等，支援語音輸入 🎤

計分方式選擇

🔵 籌碼制（推薦）

  • 記錄四位玩家各自的輸贏籌碼
  • 系統自動驗算：四人總和＋抽頭必須 = 0
  • 可使用「對戰組合」一鍵填入玩家名稱
  • 儀表板可產生完整對戰數據

🟢 現金制

  • 只記錄「我」的個人輸贏金額
  • 適合只知道自己輸贏的情況
  • 正數 = 贏、負數 = 輸
🎤
地點、備註、玩家名稱欄位旁有麥克風圖示，點擊即可語音輸入（需瀏覽器支援，建議使用 Chrome）。

📋 列表模式

首頁預設為列表模式，依日期分組顯示所有牌局。

日期分組標題

每組標題列顯示：日期、當日場次數、以及主玩家當日輸贏合計（綠色=贏、紅色=輸）。

篩選工具

篩選條件說明
關鍵字搜尋同時搜尋玩家名稱、地點、備註
開始日期只顯示該日期之後的紀錄
結束日期只顯示該日期之前的紀錄
清除篩選一鍵清空所有條件

牌局卡片操作

每張卡片右上角有三個圖示按鈕：

  • 🗓️ 行事曆圖示 — 匯出此場為 .ics 檔（可匯入 Apple / Google 行事曆）
  • ✏️ 鉛筆圖示 — 編輯此場紀錄
  • 🗑️ 垃圾桶 — 刪除此場（會跳出確認視窗）

📅 行事曆模式

點右上角切換鈕切換至「行事曆」視圖。

元素說明
淺藍色格子該日有牌局紀錄
格子內金額主玩家當日損益總和（綠=贏、紅=輸）
格子右下角數字當日場次數（例：2場）
今天日期數字以藍色圓圈標示
點擊格子開啟當日牌局清單，可新增/編輯/刪除
左右箭頭切換上/下個月

📊 戰績儀表板

點 「查看儀表板」 按鈕開啟全方位數據分析。

統計卡片

卡片說明
本月場次當月打了幾場
本月輸贏當月累積損益
本月場均每場平均輸贏
本月勝率當月贏場比例
目前連勝/連敗🔥 連勝或 💔 連敗條數
本年輸贏今年累積損益
生涯總計所有紀錄的總損益
最大單場勝利/敗北歷史最高/最低單場成績
💡
左上角「分析對象」下拉選單可切換分析任意玩家（籌碼制紀錄中出現的所有人）。

四個分析分頁

分頁內容
📊 當月比較長條圖比較當月所有玩家輸贏，可勾選要顯示的玩家
📈 累積損益折線圖呈現主玩家歷場累積損益走勢，看出長期趨勢
🤜 對戰分析與每位對手同場時的勝率與分差，找出剋星和軟柿子
⏰ 時段分析依星期幾、時段（早/午/晚/深夜）分析輸贏習慣

匯出本月紀錄

點儀表板右上角「匯出本月紀錄」→ 下載整月的 .ics 行事曆檔案，可一次匯入所有牌局到行事曆。

👥 對戰組合管理 最多 10 組

預先儲存常用牌友名單，新增牌局時一鍵套用，省去每次重新輸入姓名的麻煩。

設定新組合

1
點 Header 紫色「對戰組合」按鈕
2
點任一空格子（顯示「＋ 點擊設定」的格子）
3
填入組合名稱，例如「龍潭老班底」、「公司牌咖」
4
填入四位玩家姓名（玩家名稱支援歷史自動完成）
5
點「儲存組合」完成

使用組合新增牌局

1
點「新增牌局」，計分方式選「籌碼制」
2
看到紫色框「⚡ 快速套用對戰組合」下拉選單
3
選擇組合 → 四位玩家姓名自動填入
4
只需輸入各人輸贏金額即可儲存

編輯 / 刪除組合

在管理介面中，已設定的格子右上角有「編輯」和「刪除」按鈕。

⚡ 快速記錄輸贏

不需開啟完整表單，直接在列表頁快速記帳，適合現金制的簡易紀錄。

1
在列表頁篩選列找到「快速記錄輸贏」文字，點擊展開
2
填入日期、地點（選填）、輸贏金額
正數 = 贏、負數 = 輸（例：輸 500 填 -500）
3
點「快速記錄」，立即存入，以現金制模式記錄
⚡
快速記錄適合「只記得自己輸贏多少、其他人不重要」的情境，節省輸入時間。

💾 資料備份與還原

⚠️
資料儲存在瀏覽器本機。清除瀏覽器快取會刪除所有資料，強烈建議定期備份！

備份（匯出 JSON）

點 Header 綠色 「備份」按鈕 → 自動下載 mahjong-backup-YYYY-MM-DD.json

建議：每個月備份一次，換電腦/瀏覽器前必定備份。

還原（匯入 JSON）

點 Header 藍色 「還原」按鈕 → 選擇備份的 .json 檔案 → 確認後資料完整還原。

⚠️
匯入會覆蓋目前所有資料，執行前請確認。

換電腦 / 換瀏覽器的遷移步驟

1
在舊瀏覽器點「備份」下載 JSON 檔
2
將 JSON 檔複製到新電腦（或用 LINE / Email 傳送）
3
在新瀏覽器開啟 App，點「還原」選擇 JSON 檔
4
完成！所有紀錄完整移轉

🌙 深色模式

點 Header 右側 月亮 🌙 按鈕，即可切換深色 / 淺色模式。

偏好設定會自動儲存，下次開啟 App 時同樣套用。

💡
深夜打牌時開啟深色模式，保護眼睛，也讓旁邊的人不被螢幕亮度打擾。

📱 安裝到手機主畫面

本 App 支援 PWA（Progressive Web App），安裝後可離線使用，外觀與原生 App 相同。

🍎 iOS（Safari）

1
用 Safari 開啟 App 網址
2
點底部 「分享」 圖示（方框帶箭頭）
3
選 「加入主畫面」
4
點「加入」完成

🤖 Android（Chrome）

1
用 Chrome 開啟 App 網址
2
點右上角選單（三個點 ⋮）
3
選 「安裝應用程式」
4
點「安裝」完成
📶
安裝後首次開啟需有網路（載入靜態資源）。之後即使斷網也能正常記錄與查看紀錄。
